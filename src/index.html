		OBS Capture Script Setup Guide
		
The OBS script streams native-resolution screen frames to MYCRO (:7373) for Pixel Assist and img.* macro operations.

		

			
StepInstructions

			
1. Obtain scriptDownload obs_mycro.py or copy from the device USB drive (/obs/obs_mycro.py).

			
2. Python environmentIn OBS Studio: Tools → Scripts → Python Settings. Configure a 64-bit Python 3.10+ path with Pillow (pip install pillow).

			
3. Load scriptUnder Scripts tab, click + and select obs_mycro.py.

			
4. ConnectEnter your MYCRO device IP (and token if set), then click Connect to establish session.

					Canvas Noise Detected — Color Picker Blocked
				

				

					Your browser or an active extension (e.g. Brave Shields, CanvasBlocker, Firefox privacy.resistFingerprinting) is modifying canvas pixel data on readout.
				

				

					Why sampling is completely blocked:
					

						MYCRO macros execute conditional color checks (e.g. \ifnum{$ret}{=}{0xRRGGBB}) requiring exact 24-bit RGB values. Random noise injection corrupts sampled pixel channels, which causes macros to fail on hardware.
					

				

				

					How to unblock:
					

						Disable canvas fingerprinting protection for this origin/IP in your browser shield settings, then click Re-test & Unlock.
