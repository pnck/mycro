Combinations & Modifiers




ModifierAliasesExample


Ctrl\ctrl \control\ctrl+c (copy)


Shift\shift\shift+a (capital A)


Alt\alt \option \opt \alt+\f4 (close window)


Win/Cmd\win \cmd \gui\win+r or \cmd+space




Combo examples: \ctrl+\shift+t (reopen tab), \alt+tab (switch window)







Control Commands




CommandDescription


\delay{0.5}Set delay (seconds) for following keys


\rep{5}{abc}Repeat "abc" 5 times


\kdown{ctrl}Press and hold Ctrl


\kup{ctrl}Release Ctrl


\kup{}Release all keys









Mouse Commands




CommandDescription


\click{L}Left click (L/R/M)


\click{R,3}Right click 3 times


\move{100,-50}Move mouse (x,y)


\mdown{L}Press left button (hold)


\mup{L}Release left button









Examples




MacroDescription


Hello World\enterType text and press Enter


\ctrl+c\delay{0.2}\rep{3}{\ctrl+v}Copy, wait, paste 3 times


\win+r\delay{0.3}notepad\enterOpen Notepad (Windows)


\cmd+space\delay{0.2}terminal\enterOpen Terminal (macOS)


\mdown{L}\move{100,0}\mup{L}Drag mouse right 100px


\kdown{ctrl}ccc\kup{}Hold Ctrl, type "ccc", release
