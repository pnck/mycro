Control Commands




CommandDescription

CommandDescription

\mup{L}Release left button









Variables & Interpolation (v3)




SyntaxDescription


\set{x}{5}Set variable x (16 i32 registers; 0x hex ok)


\add{x}{-1}Add to variable


$x ${x}Variable value — only in value positions (counts, seconds, keycodes, coords)


\val{x}Type out the variable's decimal digits


$ret $timeoutRead-only: last \call result / \wait timed-out flag









Macros & Flow (v3)




SyntaxDescription


\def{dbl}[1]{#1#1}Define a macro (params #1–#9, ## = literal #)


\dbl{ab}Call it — expanded at compile time, max 4 nesting levels


\ifnum{$x}{>=}{10}{a}{b}If x >= 10 type "a" else "b" (= != < <= > >=)


\rep{$n}{ab}Repeat with a variable count









Runtime Extension (v3)




SyntaxDescription


\use{sys}Declare a namespace dependency (compile-time check)


\call{sys.free}Call an ext function; return value goes to $ret


\wait{sig}{5}Wait for signal sig up to 5s (0 = forever); sets $timeout


$sig.fieldRead a signal's payload slot (0 if unset)




Namespaces/signals are registered by the runtime; this firmware provides sys (sys.free). net/img arrive in later phases.
