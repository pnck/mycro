					Canvas Noise Detected — Color Picker Blocked
				

				

					Your browser or an active extension (e.g. Brave Shields, CanvasBlocker, Firefox privacy.resistFingerprinting) is modifying canvas pixel data on readout.
				

				

					Why sampling is completely blocked:
					

						MYCRO macros execute conditional color checks (e.g. \ifnum{$ret}{=}{0xRRGGBB}) requiring exact 24-bit RGB values. Random noise injection corrupts sampled pixel channels, which causes macros to fail on hardware.
					

				

				

					How to unblock:
					

						Disable canvas fingerprinting protection for this origin/IP in your browser shield settings, then click Re-test & Unlock.

Runtime Extension (v3)

			

				
SyntaxDescription

				
\use{sys}Declare a namespace dependency (compile-time check)

				
\call{sys.free}Call an ext function; return value goes to $ret

				
\wait{sig}{5}Wait for signal sig up to 5s (0 = forever); sets $timeout

				
$sig.fieldRead a signal's payload slot (0 if unset)

				
\call{net.send}{tag}Push a net.msg to all connected hosts ($ret = clients reached)

				
\wait{net.msg}{30}Wait for a host's event.push; read fields as $net.msg.x

				
\call{img.snap}{x,y,w,h}Snapshot a screen rect (native px, lossless) → handle in $ret ($ret<0 = error)

				
\call{img.at}{$s}{x,y}Pixel color in a snapshot → packed 0xRRGGBB

				
\call{img.diff}{$a}{$b}{tol}Count pixels diverging beyond tol (0 = identical)

				
\set{r}{\rect{\row{0xFF0000,…},…}}Pixel literal — compile-time reference snapshot (handle)

			

			
Handles: overwrite releases, \set moves, macro exit frees all — a polling loop cannot leak. Requires the capture provider (OBS script) connected (download obs_mycro.py or copy from USB drive /obs/).

			
Namespaces/signals are registered by the runtime; this firmware provides sys (free/const), net (send + net.msg signal), img (snap/at/diff). Use the Pixel Assist above to grab coordinates and colors.

		


		

			
OBS Capture Script Setup

			
The OBS script serves native-resolution screen captures to MYCRO (:7373) for Pixel Assist and img.* macro operations.

			

				
StepInstructions

				
1. Obtain scriptDownload obs_mycro.py or copy from the device's USB drive (/obs/obs_mycro.py).

				
2. Python environmentIn OBS Studio, navigate to Tools → Scripts → Python Settings. Configure a 64-bit Python 3.10+ path with Pillow installed (pip install pillow).

				
3. Load scriptUnder the Scripts tab, click + and select obs_mycro.py.

				
4. ConnectEnter your MYCRO device IP (and token if configured), then click Connect to establish the capture session.
